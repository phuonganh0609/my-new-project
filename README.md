# My New Project

Dự án thực hành quy trình làm việc cơ bản với Git và GitHub.

## Mục tiêu

- Khởi tạo Local Repository bằng `git init`.
- Kết nối với Remote Repository trên GitHub.
- Tạo file, đưa vào chỉ mục và lưu thay đổi bằng commit.
- Đồng bộ các commit lên GitHub bằng `git push`.

## Quy trình cập nhật

```bash
git add README.md
git commit -m "Update README.md"
git push origin main
```
